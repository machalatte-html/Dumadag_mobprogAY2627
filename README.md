Laboratory 1: In integrating images into the code, I used flutter's image.asset() widget to display images stored in the projects' asset folder. I first placed the image file inside the folder so flutter could access the image. To make the image dynamic, I used boolean variable called 'hasImage' with a default value of false. Inside the build() method, I used a ternary conditional operator to check its value. If hasImage is true, the image is displayed; otherwise, a SizedBox is used to leave out the image area. This allows each newsfeed post to display an image only when needed, making the widget reusable for posts with or without images.
